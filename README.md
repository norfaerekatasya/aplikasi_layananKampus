# Aplikasi Layanan Kampus

Repository ini berisi simulasi pengembangan aplikasi layanan akademik kampus dengan pendekatan **DevOps** untuk tugas UTS.

## Ruang Lingkup
- Informasi layanan akademik
- Pendaftaran mahasiswa
- Pengisian Kartu Rencana Studi (KRS)
- Informasi nilai
- Informasi pembayaran UKT

> Catatan: Ini adalah prototipe pembelajaran. Belum terhubung ke database, sistem autentikasi, maupun gateway pembayaran dan tidak digunakan untuk transaksi nyata.

## Kolaborasi Tim
| Peran | Tanggung jawab |
|---|---|
| Developer | Mengembangkan fitur dan memperbaiki kode |
| Tester / QA | Menyusun skenario uji dan melaporkan bug |
| Operations / DevOps | Mengelola pipeline, deployment, dan monitoring |

## Alur Kerja
1. Pekerjaan dicatat melalui GitHub Issues.
2. Developer membuat branch untuk setiap perubahan.
3. Perubahan diajukan melalui Pull Request.
4. GitHub Actions menjalankan pemeriksaan otomatis.
5. Reviewer memeriksa perubahan sebelum digabungkan ke branch utama.

## Teknologi
- HTML, CSS, JavaScript
- Git dan GitHub
- GitHub Actions (CI)

## Menjalankan Prototipe
Buka file `index.html` melalui browser. Tidak memerlukan instalasi server.
