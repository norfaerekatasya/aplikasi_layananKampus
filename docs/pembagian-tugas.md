# Pembagian Tugas Tim

Dokumen ini menjelaskan pembagian tanggung jawab dalam simulasi kolaborasi DevOps.

| Peran | Tanggung jawab | Bukti aktivitas GitHub |
|---|---|---|
| Developer | Membuat halaman layanan, memperbaiki bug, dan memperbarui kode | Branch, commit, Pull Request |
| Tester / QA | Menyusun skenario pengujian, memeriksa tampilan dan fungsi, melaporkan bug | Issues dan hasil pemeriksaan |
| Operations / DevOps | Menyiapkan workflow CI, memantau hasil pipeline, dan mengelola proses rilis | GitHub Actions dan dokumentasi deployment |

## Aturan kolaborasi
- Setiap pekerjaan dicatat sebagai Issue.
- Perubahan fitur dikerjakan pada branch terpisah.
- Pull Request harus menjelaskan perubahan dan cara pengujian.
- Pemeriksaan otomatis harus berhasil sebelum perubahan digabungkan.
- Jangan memasukkan password, token, atau data pribadi ke repository.
